**Homesta** is a professional **Multi-Vendor E-commerce Ecosystem** architected for the premium home furniture market. It provides a robust, scalable marketplace where multiple independent vendors and stores can subscribe, establish their digital storefronts, and reach a global audience.

---

## 🏗️ Multi-Vendor Ecosystem

Homesta is designed from the ground up to support a diverse community of sellers:
- **Vendor Onboarding**: Streamlined subscription and registration process for new stores and independent furniture makers.
- **Independent Storefronts**: Each vendor manages their own dedicated brand presence within the platform.
- **Autonomous Inventory Control**: Sellers have exclusive control over their product listings, pricing strategies, and stock management.
- **Vendor-Specific Analytics**: Dedicated dashboards for sellers to monitor their unique order flows and customer engagement.

---

## ✨ Key Features

### 👤 User Experience
- **Interactive Home Page**: Dynamic hero sections, curated categories, and featured deals.
- **Product Discovery**: Advanced filtering by category, store, price range, and colors.
- **Seamless Shopping**: Cart management, wishlist functionality, and a streamlined checkout process.
- **Order Tracking**: Real-time status updates for active shipments.

### 🏪 Seller Dashboard
- **Inventory Management**: Effortlessly add, edit, and monitor products.
- **Order Handling**: Manage customer orders and view detailed sale analytics.
- **Store Profiles**: Customize store details and maintain a professional presence.

### 🛠 Administrative Control
- **Global Management**: Oversee all categories, subcategories, and platform-wide products.
- **Data Insights**: Complete visibility into user activities and order histories.
- **UI/UX Customization**: Manage the visual structure and hierarchy of the platform.

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.x or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/YaraThabet/Homesta-2.git
   cd Homesta
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

### Running Locally

To start the development server:
```bash
npm run dev
```
*The application should now be running at `http://localhost:5173`.*

### Setting up the Proxy Server
For development with the backend API, start the proxy:
```bash
npm run proxy
```
